¿Dónde están mis proyectos?
Las tarjetas de arriba son el historial guardado en este dispositivo. El proyecto abierto está marcado «ABIERTO» y se guarda automáticamente. Para guardar un archivo independiente, pulsa «Guardar archivo JSON» o «Exportar ZIP».
Ubicación de archivos y cómo elegir carpeta

Para abrir un respaldo, toca «Importar JSON / ZIP» y elige el archivo en Archivos o en el selector de tu teléfono.
